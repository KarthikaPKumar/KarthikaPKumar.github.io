# Kathy · The Series

Reference-faithful portfolio adaptation. Attribution and source revision: [ATTRIBUTION.md](ATTRIBUTION.md).

All personal content is in `src/data/portfolio.ts`. The original owner's photographs, résumé and credentials are excluded. Career highlights replace unverified awards and certifications. The résumé overlay is a printable career summary until Kathy supplies her résumé PDF.

Run `npm ci`, then `npm run build`. Build writes the GitHub Pages preview to `../revamp/` with base `/kathy/revamp/`. `npm run preview` serves the built version locally. Commit both source and generated preview when publishing.

Includes the original opening, profiles, parallax hero, highlight reel, magnetic buttons, custom cursor, tilt cards, scroll-pinned project rail, season tabs, skill evidence, progress indicators and contact finale. Project overlays additionally link to Kathy's deployed demos and describe evidence limitations.
